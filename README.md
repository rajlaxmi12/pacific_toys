# 📖 Overview

**Pacific Toys** is a modern full-stack online marketplace built using the **Node.js + Express.js + MongoDB** stack. The platform allows users to browse, search, buy, and sell collectible as well as children's toys through an intuitive and responsive interface.

Registered users can securely create accounts, upload product images, manage their own listings, edit or delete products, leave reviews, and explore toys posted by other users. The application follows the **MVC Architecture**, implements **RESTful Routing**, and integrates **Cloudinary** for cloud image storage.

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/rajlaxmi12/Pacific-Toys.git
```

Move into the project folder

```bash
cd Pacific-Toys
```

Install Dependencies

```bash
npm install
```

---

## Create a `.env` File

```env
ATLASDB_URL=

SECRET=

CLOUD_NAME=

CLOUD_API_KEY=

CLOUD_API_SECRET=
```

---

## Run the Application

```bash
node app.js
```

---

## Open in Browser

```
http://localhost:8080
```
